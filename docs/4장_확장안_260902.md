### 4.1.5 판단 기준과 처리 노드의 대응

앞서 제시한 네 가지 판단 기준은 하나의 노드에 일대일로 배정되지 않는다. 상위어 유사성과 표현 명시성은 후보를 탐색하기 이전에 입력 메시지의 해석 범위를 규정하는 기준이므로 메시지 분석과 쿼리 재구성 단계에서 처리되며, 거래 유형과 역할 상보성은 확보된 후보를 평가하는 기준이므로 선택 단계의 하위 Selector에 배정된다. 각 기준이 처리되는 위치는 [표 1]과 같다.

**[표 1] 판단 기준과 처리 노드의 대응**

| 판단 기준 | 처리 단계 | 담당 노드 |
|---|---|---|
| 4.1.1 Matching Target의 상위어 유사성 | 해석 · 탐색 · 최종 판정 | Message Analyzer(상위어 추출) → Query Reformer(상위어 일반화 전략) → Evaluator |
| 4.1.2 표현 명시성에 따른 추론 | 해석 · 탐색 · 선택 | Message Analyzer(의도 추론) → Query Reformer(암시화·구체화 전략) → PersonaMatch |
| 4.1.3 거래 유형(Type) | 선택 | TypeMatch |
| 4.1.4 역할 상보성 | 탐색 · 선택 | Query Reformer(상보적 메시지 변환) → RoleMatch |

이 가운데 상위어는 Message Analyzer가 추출한 시점에 공유 상태에 고정되어 이후 모든 노드가 동일한 값을 참조한다. 이는 재탐색이 반복되는 동안 판단의 기준점이 이동하는 것을 방지하기 위한 것이며, 그 구체적인 기제는 4.2에서 기술한다.

### (5) Evaluator

Evaluator는 Main Selector가 전달한 후보의 적합성을 검증하고, 부적합할 경우 재탐색 여부를 결정하는 노드이다. 이 노드는 시스템 내에서 유일하게 전체 대화 기록과 실패 이력을 열람할 수 있다. 하위 Selector가 각자의 기준에 한정된 시야를 갖고 Main Selector가 그 결과의 통합에 한정되는 것과 달리, Evaluator는 지금까지의 판단 경로 전체를 참조하여 최종 판정을 내린다.

Evaluator가 참조하는 정보는 사용자 입력 메시지, Main Selector가 선택한 후보와 그 확신도, 세 하위 Selector의 판단 내역, 전체 후보군 목록, 누적된 실패 이력, 그리고 상태에 고정된 Matching Target과 상위어이다.

판정은 사전에 규정된 기준 간 우선순위에 따라 이루어진다. Matching Target 유사도와 역할 상보성이 동등한 최상위 기준이며, 거래 유형 일치와 페르소나 유사성은 그보다 낮은 순위를 갖는다. 두 최상위 기준이 충돌하는 경우 Evaluator는 어느 쪽을 우선하였는지와 그 근거를 판정문에 기술하도록 규정되어 있다. 이는 기준의 포기가 발생한 지점을 사후에 특정할 수 있도록 하기 위한 장치이다.

부적합 판정의 대표적 근거는 정보의 불균형 또는 역할 충돌이다. 두 메시지가 모두 정보를 요구하기만 하거나 모두 제공하기만 하는 경우 상호작용이 성립하지 않으므로, 표현상의 유사성이 높더라도 매칭으로 인정되지 않는다. 또한 Main Selector가 산출한 확신도가 기준값에 미달하는 경우에도 부적합으로 처리된다.

Evaluator의 동작은 평가 회차에 따라 분기한다.

**첫 번째 평가**에서는 후보의 적합 여부를 판정하고, 적합하면 흐름을 종료한다. 부적합하면 어느 노드의 어떤 판단에서 오류가 발생하였는지를 분석하여 Orchestrator에게 전달하고 재탐색을 지시한다. 이때 지시는 실패 유형에 따라 구체화된다. 역할 상보성이 충족되지 않은 경우에는 Matching Target의 입장에서 작성된 상보적 쿼리를, Matching Target 유사도가 부족한 경우에는 상위어 중심의 쿼리를 Query Reformer에 요청한다. 즉 재탐색은 동일한 절차의 단순 반복이 아니라, 직전 실패의 원인에 대응하는 방향으로 조정된 재시도이다.

**두 번째 평가**에서는 더 이상의 반복이 허용되지 않으므로 판정 방식이 달라진다. Evaluator는 현재 후보뿐 아니라 전체 후보군과 실패 이력에 기록된 후보까지 함께 검토하여 가장 나은 하나를 선택한다. 이 과정에서 Main Selector의 판단과 다른 후보를 선택할 수 있으며, 앞선 회차에서 기각되었던 후보의 확신도가 더 높은 경우 이를 최종 결과로 채택할 수 있다. 선택된 후보가 모든 기준을 충족하지 못하는 경우에는 어떤 점에서 미흡한지와 그럼에도 이 후보가 상대적으로 적합한 이유를 판정문에 포함하고 흐름을 종료한다.

이러한 이원적 분기는 시스템이 결과를 산출하지 못한 채 종료되는 상황을 방지하는 동시에, 종료된 결과가 어떤 수준의 판정을 거친 것인지를 구분 가능하게 한다.

### (6) 보조 노드: Message Analyzer와 Web Search Module

두 보조 노드는 메인 노드와 달리 항상 실행되지 않으며, Orchestrator가 입력 메시지의 성격을 판단하여 필요한 경우에만 호출한다.

**Message Analyzer**는 입력 메시지의 목적이나 맥락이 모호할 때 호출되어, 메시지를 매칭에 활용 가능한 형태로 구조화한다. 산출물은 Matching Target, 그 상위어, 도메인, 대상 유형이며, Matching Target은 하나의 메시지에서 최대 세 개까지 도출될 수 있다. 이 노드의 특징은 명시적으로 표현되지 않은 대상도 정서와 맥락으로부터 추론한다는 점에 있다. 예컨대 "하… 너무 춥다"와 같은 메시지에서 따뜻한 음식이나 실내 활동을 Matching Target으로 제시하는 방식이다. 이는 4.1.2에서 규정한 암시적 표현의 해석에 해당한다. 또한 본 시스템은 사용자와 대화를 주고받지 않으므로, 정보가 부족하더라도 추가 질의를 요청하지 않고 확보된 범위 안에서 해석을 확정하도록 규정되어 있다.

**Web Search Module**은 메시지에 포함된 고유명사, 신조어, 줄임말의 의미를 시스템이 판단하기 어려울 때 호출된다. 외부 검색 결과를 바탕으로 해당 표현의 의미와 관련 고유명사를 제시하며, 다의어인 경우에는 최신 사용례를 우선하여 해석한다. 이 노드의 출력은 그 자체로 사용자에게 제공되는 정보가 아니라, 이후 단계의 의미 해석을 보강하기 위한 입력으로만 사용된다. Ⅰ장에서 예시한 "저 뷮인데 이번에 같이 가실 분?"과 같이 팬덤 용어가 포함된 메시지가 이 노드의 호출 대상에 해당한다.

두 노드가 보조적 위치에 놓이는 이유는 호출 비용 때문이다. 모든 입력에 대하여 구조화와 외부 검색을 수행하면 응답 지연과 모델 호출 비용이 선형으로 증가하므로, 해석 난이도가 높은 입력에 한정하여 선택적으로 호출하는 구조를 채택하였다.

### (7) 재탐색 루프와 종료 조건

Evaluator가 부적합으로 판정하면 흐름은 Orchestrator를 거쳐 Query Reformer로 회귀한다. 이때 실패한 쿼리, 부적합했던 후보, 그리고 실패 사유가 공유 상태의 실패 이력에 누적된다. 실패 이력은 동일한 쿼리와 후보의 조합이 중복 기록되지 않도록 관리되며, Query Reformer는 이를 참조하여 이전과 다른 재구성 전략을 적용한다. 이 기제에 의해 재탐색은 동일한 오류를 반복하지 않는다.

루프의 종료는 두 개의 상한에 의하여 보장된다. 하나는 평가 횟수의 상한이고 다른 하나는 재시도 횟수의 상한이며, 본 연구의 구현에서는 두 값을 모두 2로 설정하였다. 평가 횟수가 상한에 도달하면 Evaluator는 앞서 기술한 최종 평가 분기로 진입하여 확보된 후보 가운데 하나를 선택하고 종료한다. Main Selector가 적합한 후보를 전혀 산출하지 못하는 경우에도 재시도 횟수가 상한에 도달하면 동일하게 종료 처리된다.

이 설계에 따라 하나의 입력이 통과하는 노드의 수는 연속적인 값을 갖지 않고 몇 개의 이산적인 값으로 수렴한다. 재탐색이 발생하지 않은 최소 경로는 Orchestrator → Query Reformer → Selector → Evaluator의 네 노드로 구성되며, 루프가 한 차례 발생하면 기본 경로가 한 번 더 수행되고, 여기에 보조 노드 호출이 더해지면 그만큼의 노드가 추가된다. 두 상한이 함께 규정하는 경로 길이의 상계가 곧 시스템이 소요할 수 있는 최대 호출 횟수이며, 이는 응답 지연과 모델 호출 비용이 입력의 해석 난이도와 무관하게 구조적으로 유계임을 의미한다. 해당 분포의 실측 결과는 Ⅴ.2에서 제시한다.
