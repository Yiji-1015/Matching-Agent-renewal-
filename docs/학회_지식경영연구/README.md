## 경영정보학연구(ISR)와의 핵심 차이

| | 지식경영연구 | 경영정보학연구 |
|---|---|---|
| 참고문헌 | **APA** — `../참고문헌.md` 재활용 가능 | 고유 형식 — 31건 재변환 필요 |
| 접수 조건 | KCI 유사도 10% 이하 (통과 예상 — 비교 DB가 KCI라 DBpia 수록 발표문은 무관) | 없음 |
| 키워드 제약 | **'지식경영' 용어 필수** | 없음 |
| 게재료 | 25만원(15p) + 초과 페이지당 2만원 | 미확인 |
| 심사료 | 없음 | 없음 |
| 편집위원장 소속 | 중앙대 | — |
| 사무국 | **경희대 호텔관광대학** | — |
| 중복게재 조항 | 윤리규정에 없음 (편집방침 미확인) | 편집방침 6항에 명시 |

## 선행 발표 처리

학술대회 발표문이 **DBpia에 수록(KCI 미수록)**되어 있다.

- **유사도 검사**: KCI DB 기준이므로 걸리지 않을 것으로 판단. 참고문헌 제외 옵션을 켜고 실행
- **중복게재**: 심사자가 검색으로 발견할 수 있으므로 **Cover letter에 선행 발표를 먼저 고지**한다.
  문안과 확장 근거표는 `학회규정.md` "① KCI 유사도 검사" 절에 있다.

## 남은 결정 변수

- 키워드에 '지식경영' 관련 용어를 넣을 수 있는가 (필수 요건)
- 게재료 25만원 + 15페이지 초과분 부담을 감수할 것인가
- 편집방침의 중복게재 조항 유무 (미확보)
