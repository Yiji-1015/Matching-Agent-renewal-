## 경영정보학연구(ISR)와의 핵심 차이

| | 지식경영연구 | 경영정보학연구 |
|---|---|---|
| 참고문헌 | **APA** — `../참고문헌.md` 재활용 가능 | 고유 형식 — 31건 재변환 필요 |
| 접수 조건 | **KCI 유사도 10% 이하** ← 최대 관문 | 없음 |
| 키워드 제약 | **'지식경영' 용어 필수** | 없음 |
| 게재료 | 25만원(15p) + 초과 페이지당 2만원 | 미확인 |
| 심사료 | 없음 | 없음 |
| 편집위원장 소속 | 중앙대 | — |
| 사무국 | **경희대 호텔관광대학** | — |
| 중복게재 조항 | 윤리규정에 없음 (편집방침 미확인) | 편집방침 6항에 명시 |

> **결정 시 핵심 변수는 KCI 유사도 10%다.** 통과하지 못하면 이 학회는 선택지에서 제외된다.
> 투고 준비보다 유사도 검사를 먼저 돌릴 것.
