## ISR에 종속된 원고 요소 — 학회 변경 시 되돌릴 것

| 항목 | ISR 규정 | 비고 |
|---|---|---|
| 참고문헌 표기 | `저자명, "제목", 학술지명(이탤릭), Vol.X, No.Y, 연도, pp. xx-xx.`<br>제1저자만 `성, Initial.`, 공동저자는 `Initial. 성`, 연결은 `and`, **DOI 없음** | APA와 전혀 다름 |
| 배열 순서 | 국내(가나다) → 국외(알파벳) → URL | |
| 본문 인용 | `(저자, 연도)`, 영문 3인 이상 **`et al.`**, 복수 인용은 `;` + 알파벳순 | "외" 사용 불가 |
| 장 번호 | **로마자** Ⅰ·Ⅱ·Ⅲ (절은 아라비아 1, 1.1) | 다른 학회는 아라비아인 경우가 많음 |
| 표·그림 | `표 1` / `그림 1` | `[표 1]`·`<표 2>` 형식 불가 |
| 초록 | 국문 + 영문, **영문 200 words 이내** | |
| 분량 | **30매 이내** | |
| 파일 구성 | 원고(저자정보 없음) / 별지(저자정보) / 윤리규정 서약서 **3종 분리** | 블라인드 심사 |
| 회원 자격 | 저자 1인이 종신회원 또는 당해연도 정회원 (연회비 약 5만원) | 미납 상태 |

## 다른 학회 후보 (2026-09-02 조사)

투고 학회를 재검토 중이며, 조사된 후보는 다음과 같다.
자세한 비교는 대화 기록 참조.

| 순위 | 학술지 | 발행 학회 | 비고 |
|---|---|---|---|
| 1 | 지식경영연구 | 한국지식경영학회 | LangGraph 계열 RAG 에이전트 논문 선례 2편 |
| 2 | 한국인터넷정보학회논문지 | KSII | 멀티에이전트·RAG 설계 논문 다수, 비용 저렴 |
| 3 | 한국IT서비스학회지 | 한국IT서비스학회 | DSRM 논문에 가장 친화적 |

> ISR은 주제 적합도가 가장 높으나(2025년 27권 3호에 RAG + 멀티에이전트 설계 논문 게재),
> 학술대회 발표문의 교신저자였던 지도교수가 해당 학회 임원(부회장 다수, 2023~ AI연구회장)이어서
> 재검토 대상이 되었다.
