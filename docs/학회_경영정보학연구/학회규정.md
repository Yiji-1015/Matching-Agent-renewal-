발행: 한국경영정보학회 (KMIS) / 학술지: 경영정보학연구 (Information Systems Review, ISR)
정리: 2026-09-02
확보 범위: 편집방침, 투고요령(논문작성요령 포함), 심사 시행세칙(제1~9조)
미확보: 연구윤리 규정 본문, 게재료 금액, 논문 윤리규정 서약서 양식

> ⚠️ **"양식 자유" 아님.** 투고요령에 *"제출논문은 반드시 경영정보학연구의 원고작성지침에 따라
> 작성함. 원고작성지침을 따르지 않은 논문은 반려됨"* 이라고 명시되어 있다.

> **참고문헌 표기·인용 방식·장절 번호·초록·분량은 저자가 지침대로 맞춰야 한다.**

## 1. 투고 자격 및 제출물

| 항목 | 내용 |
|---|---|
| 투고료 | 없음 |
| 자격 | 저자 **중 1인**이 한국경영정보학회 **종신회원** 또는 **당해연도 회비 납부 정회원**<br>→ **윤이지 직접 가입으로 해결 예정** (연회비 약 5만원) |

| 권장 사항 | 투고 전 **KCI 문헌 유사도 검사** |

### 제출 파일 3종 (반드시 분리)

| 파일 | 내용 |
|---|---|
| **파일 1 — 원고파일** | 1쪽에 국문·영문 원고제목, 국문·영문 요약(영문 200 words 이내), keywords.<br>**본문에 저자 관련 내용이 일절 포함되어서는 안 됨** (블라인드 심사) |
| **파일 2 — 별지파일** | 논문 제목, 저자 국문/영문 성명, 소속, 연락처, 요약, 200자 이내 저자 소개(E-mail 포함)<br>※ **FAQ**: 투고 시에는 **간단한 연락처와 논문만** 제출하면 되고, **저자 소개 및 사진은 게재 확정 후** 제출. 투고요령 원문과 다소 차이가 있으므로 편집간사에게 확인 권장 |

## 2. 논문 작성 요령 (투고요령 4항) — ★ 반드시 준수

### 가. 분량
**30매 이내.** ("매"의 기준이 명시되어 있지 않음 — 편집간사에게 확인 권장)

### 나. 용어 표기
- 학술용어는 **국문 표기**, 이해를 돕기 위해 원어를 괄호 안에 병기 가능
- 번역이 곤란한 경우 원어 그대로
- 인명·지명·고유명사는 원어, 숫자는 아라비아 숫자, 단위는 미터법

### 다. 장절 번호 — ★ 현재 원고와 다름

| 구분 | 표기 |
|---|---|
| 장 | **로마자** Ⅰ, Ⅱ, Ⅲ … |
| 절 | 아라비아 숫자 1, 1.1, 2, 2.1, 2.2 … |

> 현재 원고는 `1. 서론 / 2. 배경 및 기존연구 / …`로 아라비아 숫자를 쓰고 있다.
> → `Ⅰ. 서론 / Ⅱ. 배경 및 기존연구 / Ⅲ. 연구방법 / Ⅳ. 제안 시스템의 설계 구조 /
> Ⅴ. 시연 및 평가 / Ⅵ. 결론` 으로 전환 필요.

### 라. 표·그림
해당번호(**표 1**, **그림 3**)와 제목 또는 설명을 붙일 것.
> 현재 원고의 `[표 1]`, `[그림 1]`, `<표 1>`, `<표 2>`, `<그림 O>`가 혼용되고 있다.
> **`표 1` / `그림 1` 형식으로 통일**하고 번호를 재부여해야 한다.

### 사. 요약
**국문·영문 모두** 작성, **영문 200 words 이내**, 본문 앞에 배치.

### 아. 제1면
국문 및 영문 원고제목, 저자 성명 및 소속(→ 별지), **영문 Key Words** 제시.

## 3. 참고문헌 표기 (투고요령 4-마) — ★ APA 아님

### 배열 순서
**국내문헌 → 국외문헌 → URL주소** 순.
- 국내문헌: 가나다순
- 국외문헌·URL: 알파벳순
- 동일저자 2편 이상: **연도순** (가장 최근 논문이 마지막)
- 동일저자·동일연도 2편 이상: 연도 뒤에 a, b, …

### 저자명 표기 규칙
- **대표저자(제1저자)**: `성, Initial.`
- **공동저자**: `Initial. 성`
- 연결: 저자2인 → `저자1 and 저자2` / 3인 이상 → `저자1, 저자2 and 저자3`

### 유형별 형식

**a. 도서**
```
저자명, 도서명(이탤릭), 출판사, 출판지, 연도.
```
> 영문 도서명은 of, and, the, a, for 등 전치사·접속사를 제외한 모든 단어를 대문자 표기.

예: `Brown, K., R. A. Scamell and R. Hirschheim, Method of MIS Research, The Free Press, New York, NY, 1988.`

**b. 학술지 및 학회 프로시딩**
```
저자명, "논문 제목", 학술지명 또는 학회명(이탤릭), Vol.X, No.Y, 연도, pp. xx-xx.
```
- 논문 제목: **따옴표**, 영문은 **sentence case**(첫 단어와 고유명사만 대문자)
- 학술지명: **이탤릭**, **Headline case**(전치사·접속사 외 모두 대문자)
- 국문: `제3권, 제2호` 형식

예: `Adams, D. A., "User managers' systems need", MIS Review, Vol.7, No.2, 1997a, pp. 27-41.`
예: `홍길동, 이순신, "전자정부의 미래와 전망", ISR학회지, 제3권, 제2호, 1999, pp. 10-15.`

**c. Book Chapter**
```
저자명, "Chapter 제목", in 저자명 (eds.), 도서명(이탤릭), 출판사, 출판지, 연도, pp. xx-xx.
```

**d. URL**
```
저자명 또는 기관명, "제목", (발행기관명), 연도, Available at URL.
```

**e. 학위논문**
```
저자명, 제목(이탤릭) (석사학위논문/박사학위논문), 학위기관, 연도.
```

> **DOI는 예시에 없다.** 현재 `../참고문헌.md`의 DOI는 전부 제거 대상.

### 본문 인용 (투고요령 4-바)
- 형식: **`(저자, 출판년도)`**
- **3인 이상**: `첫 저자 등` / 영문은 **`첫 저자 et al.`**
- 한 번에 여러 논문: **`;`로 구분**, 국내문헌 가나다순 → 국외문헌 알파벳순
- 동일 저자의 여러 논문 인용 시 각 논문마다 저자명을 명시하고 연도순으로 배열

예: `홍길동 등(1987)에 의하면 -----`
예: `-------- 한다(Brown et al., 1988).`
예: `-------- 한다(Adams, 1997a; Smith, 2010; 갑돌이, 갑순이, 1992; 홍길동, 1987; 홍길동, 1994).`

> 현재 원고는 `Ren 외(2021)`, `Wang 외(2025)`처럼 **영문 저자에 "외"를 쓰고 있다.**
> 규정상 영문 저자는 **`et al.`** 이므로 `Ren et al.(2021)`로 통일해야 한다.

## 4. 심사 절차

```
투고 → 편집위원장 접수 승인·논문번호 부여 → 편집위원 배정
     → 심사자 2인 선정 → 1차 심사(심사의뢰일로부터 5주 이내)
     → 판정 통보 → 수정본 + 평가의견 답변서 제출(6개월 이내)
     → 2차 심사 이후는 3주 이내 → 게재
```

| 단계 | 기한 |
|---|---|
| 1차 심사 | 심사의뢰일로부터 **5주** |
| 2차 심사 이후 | **3주** |
| 수정본 제출 | 수정요구일로부터 **6개월**. 초과 시 **포기 간주 → 신규 투고로 처리** |

- 심사는 **비공개**, 저자는 게재 확정 전까지 **익명**
- 수정 요구에 동의하지 않으면 **그 요구가 잘못되었음을 설득력 있게 밝혀야** 함 (최종 판단은 편집위원회)
- 게재 확정 후에도 편집위원회가 투고요령·편집방침에 맞춘 수정을 요구할 수 있음

### 심사위원·편집위원 추천 — ★ 이해관계 조항

저자는 **심사위원 2인까지**, **편집위원 1인**을 추천할 수 있다(성명·소속·이메일·연락처 명기).
단 추천 대상은 다음을 **모두** 만족해야 한다.

- 저자들과 **다른 기관 소속**일 것
- **사제지간이 아닐 것** (다른 기관이어도 사제지간이면 추천 불가)
- 논문 제출 시점으로부터 **5년 전까지의 기간 동안 동일 기관에서 근무·연구한 이력이 없을 것**

> 최종 심사위원은 편집위원이 결정하며, **2인 중 1인까지만** 저자 추천에서 선정하고
> 나머지 1인은 편집위원이 연구 분야를 고려해 선정한다.

## 5. 심사 평가 항목 (심사 시행세칙 제5조) — 원고 준비 체크리스트

각 항목을 5점 척도(매우 열악 / 열악 / 보통 / 우수 / 매우 우수)로 평가한 뒤,
종합의견으로 **수정 후 게재 / 수정 후 재심사 / 게재 불가** 중 택일한다.

| # | 심사 항목 | 현재 원고 대응 | 상태 |
|---|---|---|---|
| 1 | 현실적인 시사점 | Ⅵ장 실무적 함의 | 보강 완료 |
| 2 | 독창성 | Ⅵ장 "집단(blocks) 구획이 주어지지 않는 매칭" 문제 규정 | 보강 완료 |
| 3 | 연구방법의 적절성 | Ⅲ장 DSRM, Ⅴ장 평가 설계("두 층위"→**세 층위** 수정 필요) | 수정 필요 |
| 4 | 내용의 타당성 | Ⅳ장 — **Evaluator 노드 절 누락**, 판단기준↔노드 대응 부재 | **미해결** |
| 5 | 서술의 논리성 | 문체 혼재, Ⅱ장 Ren→Steiner 문단 단절 | 수정 필요 |
| 6 | 제목과 요약문 | 국문 초록·영문 Abstract **템플릿 상태** | **미작성** |
| 7 | 참고문헌 인용 | **템플릿 예시 문헌 방치 + APA 형식 + 번호식 인용 잔존** | **미해결** |

### 편집위원장의 최종 판정 기준 (제6조)

| 심사위원 A | 심사위원 B | 처리 |
|---|---|---|
| 게재불가 | 게재불가 | 게재불가 확정 |
| 게재불가 | 수정 후 재심사 | 편집위원회 결정으로 게재불가, 또는 B의 재심 결과로 판정. 제3심사위원 추가 의뢰 가능 |
| 게재불가 | 수정 후 게재 | 편집위원회 결정으로 게재반대, 또는 B의 재심 결과로 "수정 후 재심사" 판정. 제3심사위원 추가 의뢰 가능 |
| 수정 후 재심사 | 수정 후 재심사 | 수정 논문에 대한 A·B 재심 결과로 판정 |
| 수정 후 재심사 | 수정 후 게재 | 〃 |
| 수정 후 게재 | 수정 후 게재 | 〃 |

> 한 명이라도 「게재불가」를 주면 편집위원회 재량 구간으로 들어간다.
> 두 심사자 모두에게서 최소 「수정 후 재심사」를 받는 것이 실질적 목표.

「수정 후 게재」/「수정 후 재심사」 의견을 낸 심사자는 특별한 사유가 없는 한 **다음 라운드에도 동일 심사자**로 선정된다.

## 6. 중복게재 — 선행 공표 정리

편집방침 6항: *"게재 신청된 논문은 **다른 간행물에 발표되지 아니한 것**이어야 하며,
논문의 내용에 대한 책임은 논문 저자에게 있다."*

### 선행 공표 이력

| 구분 | 내용 |
|---|---|
| 학술대회 | 2025 융합학술대회, **분야: 경영정보** (한국경영정보학회 관련 트랙) |
| 발표문 | `docs/2025 융합학술대회 논문_Designing a RAG-Based Matching Agent with Role-Differentiated LLMs.docx` |
| 저자 | 주저자 윤이지(경희대 빅데이터응용학과) / **교신저자 이경전(경희대 경영학과 및 빅데이터응용학과)** |
| 분량 | 본문 약 18,400자, 5장 구성, 참고문헌 16건 |
| 학위논문 | `docs/석사학위논문.pdf` (윤이지) |

### 학술대회본 대비 현재 원고의 확장 내역

| 구분 | 학술대회본 (2025) | 현재 원고 |
|---|---|---|
| 장 구성 | 서론 / 관련 연구 / 설계 구조 / 시연·평가 / 결론 (5장) | 서론 / 배경·기존연구 / **연구방법** / 설계 구조 / 시연·평가 / 결론 (6장) |
| 연구방법론 | **없음** | **Ⅲ장 DSRM 신설** (Peffers et al., 2007) |
| 제어 흐름 검증 | 없음 | **Ⅴ.2 노드 통과 수 분포 분석 신설** |
| 교정률 평가 | 80건 중 약 49% (서술만) | Ⅴ.3 — 판정 기준 3종 사전 명시, 비블라인드 조건 한계 명시 |
| 제3자 평가 | **없음** | **Ⅴ.4 블라인드 쌍대 비교 설문 전면 신설**<br>(2025-09-09·09-15 실시 = 학술대회 이후 수행) |
| 신뢰도 분석 | 없음 | **관측 일치도·Fleiss κ·Randolph κ·Gwet AC₁ 삼각 검증 신설** (GRRAS 준거) |
| 양방향 매칭 실험 | 34쌍 중 15쌍(약 44%) 보고 | **삭제** (재현 데이터 없음) |
| 결론 | 기여 2건 + 한계 + 향후 2건 | 학술적 함의 2건 + 실무적 함의 + 한계 + 향후 3건 |
| 참고문헌 | 16건 (IEEE 번호식) | 30건 (저자–연도식) |

> **핵심 방어 근거**: 평가 부분(Ⅴ장)이 사실상 전면 교체되었다. 특히 제3자 블라인드 설문은
> 학술대회 발표 **이후**인 2025년 9월에 수행된 신규 데이터이며, 학술대회본에서 보고했던
> 양방향 매칭 실험은 제거되었다. 연구방법론(Ⅲ장)과 결론의 이론적 함의도 신규 작성이다.

### 그럼에도 확인해야 할 것

- [ ] **학술대회 발표문이 ISSN·DOI가 부여된 논문집(Proceedings)으로 정식 출판되었는지**,
      아니면 초록집·발표자료 수준인지. 전자라면 "다른 간행물에 발표"에 해당할 수 있다.
- [ ] 해당 학회의 **학술대회 → 학술지 확장 게재 관행**. 통상 같은 학회 트랙 발표문의
      저널 확장은 권장되나, 투고 시 그 사실을 고지하도록 요구하는 경우가 많다.
- [ ] 연구윤리 규정 본문의 중복게재·자기표절 조항
- [ ] **KCI 문헌 유사도 검사** 실시 (학회 권장 사항)

> 고지 방법: 투고 시스템의 비고란, 또는 원고 첫 쪽 각주에
> "본 논문은 2025 융합학술대회에서 발표한 내용을 대폭 확장·수정한 것임" 형태로 명시.
> 단 **원고파일은 블라인드**이므로 저자 식별이 가능한 형태의 각주는 별지파일에 넣을 것.

### ⚠️ 저자 구성 변경 확인 필요

학술대회본의 교신저자는 **이경전 교수**이나, 현재 KCI 원고의 저자는
**윤이지 + 조희선**으로 구성되어 있고 이경전 교수는 포함되어 있지 않다.

동일 연구의 확장본에서 저자가 빠지는 경우 연구윤리상 **당사자 동의**가 필요하며,
학회에 따라 소명을 요구할 수 있다. 투고 전 반드시 정리할 것.

### ★ 게재 확정 후 저자가 해야 할 작업 (FAQ)

*"게재확정이 되면, 투고자께서 **2단쓰기 및 게재확정 투고요령**에 맞춰 논문을 수정해 주셔야 합니다.
출판사에서 일괄적으로 편집을 하기는 하지만, 그래프나 표, 그림들이 들어간 논문은
출판사에서 편집하기 힘들기 때문입니다."*

- **투고 시점**: 1단/2단 무관, 투고요령만 맞추면 됨
- **게재 확정 후**: 저자가 직접 **2단 편집**으로 재작업 + 저자 소개·사진 제출

> 본 원고는 그림 1(전체 흐름도), 그림 2(노드 통과 수 히스토그램), 표 1(쌍대 비교),
> 표 2(신뢰도 지표)를 포함하므로 이 재작업 대상에 정확히 해당한다.
> **2단 폭에서 깨지지 않도록 표·그림을 미리 준비해 둘 것.**
