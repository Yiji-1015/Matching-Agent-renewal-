## §2 관련 연구 — 확인 완료

### 검증 통과

- **Gale, D., & Shapley, L. S. (1962).** College admissions and the stability of marriage.
  *The American Mathematical Monthly, 69*(1), 9–15. — 서지·내용 모두 정확.
- **Roth, A. E. (1982).** The economics of matching: Stability and incentives.
  *Mathematics of Operations Research, 7*(4), 617–628. — 정확.
  원문 초록의 두 결과("안정성과 진실 표명을 동시에 보장하는 절차는 없다" / "일방 집단에
  대해서는 진실 표명을 보장하는 절차가 존재한다")와 초안 서술이 정확히 일치.
- **Steiner, P. (2019).** Economy as matching. *Política & Sociedade, 18*(43), 14–45.
  DOI 10.5007/2175-7984.2019v18n43p14 — 서지 정확. 저자는 Philippe Steiner (Sorbonne Université).
- **Tsagkias 외 (2020).** *ACM SIGIR Forum, 54*(1). — 내용 확인됨.
  본문에서 고객 의도 3분류, 멀티모달 문서, 수익/만족도 상충을 모두 다룸.
- **Qian 외 (2024). ChatDev.** PDF 확인. 저자 14인 명단이 참고문헌 목록과 일치.
  "소프트웨어 개발 워크플로를 역할별 에이전트로 분해" 서술은 원문과 부합.
- **Ma 외 (2023).** Query Rewriting for Retrieval-Augmented Large Language Models.
  Rewrite–Retrieve–Read 구조 ✓ (원문 초록에 그대로 등장).

### 수정 필요

1. **Steiner 인용의 절 번호 `(§1.1)`이 틀림.**
   - "양측 행위자가 서로에 대한 정보를 가지고 세 과제를 수행" 대목 → 원문 **§2.1
     *Matching: market and arena*** (p.17).
   - 블록/청산소/매칭 소프트웨어 대목 → 원문 **§3.1 *Blocks, Clearinghouse and
     matching software*** (p.24).
2. **Steiner의 세 과제 번역.** 원문은 *screening, selecting and then matching*.
   초안의 "필터링·선택·성사"에서 "필터링"은 **"선별"**이 정확.
3. **Tsagkias의 의도 3분류 출처.** navigational/informational/transactional는 원문이
   **Broder(2002)**에서 가져와 전자상거래에 적용한 것. "Tsagkias 외가 지적한다"는
   서술은 오해 소지가 있으므로 출처 관계를 밝히는 편이 안전.
4. **Seedat & van der Schaar (2024) Matchmaker의 3단계 명칭.**
   원문 표현은 *candidate generation, refinement and confidence scoring*.
   초안의 "Generator–Refiner–Scorer"는 의역이므로 원문 용어로 맞추거나 의역임을 드러낼 것.
   ※ arXiv:2410.24105. **정식 게재 여부(NeurIPS 본회의/워크숍) 미확인 — 확인 필요.**
5. **Trivedi 외 (2023) IRCoT 설명.** IRCoT는 검색과 CoT를 **교차(interleaving)**하는
   방식. 초안의 "재귀적 검색"은 부정확 — "반복적/교차적"으로.

## §4 확정 수치 (재확인 완료 — 변경 금지)

원자료: `docs/ratings_ver3.xlsx`의 **`rating2` 시트만 실데이터**.

설문은 동일 평가자 3인(A·C·E)이 40문항을 두 차례에 나누어 평가한 **하나의 조사**다.
1차 2025-09-09(문항 1–20), 2차 2025-09-15(문항 21–40)이며 두 차수의 문항은 겹치지 않는다.
저자 확인(2026-08-30): 세 평가자는 **두 차수 모두 동일한 사전 설명 절차**를 거쳤고,
차수를 나눈 것은 문항 배분일 뿐이다. 따라서 **40문항 120판정을 하나의 표본으로 통합**하며,
이것이 주 분석이다. 차수별 수치는 견고성 확인용 보조 지표로만 병기한다.

1차 구글폼에는 5건의 응답이 있으나 2건은 사전 설명을 받지 않은 패널 외 응답이므로
분석에서 제외한다. 결과 의존적 제외가 아님의 방증: 해당 2인의 선택률은 각각
17/20(85%)이며, 포함해도(1차 5인 전체 91/100 = 91.0%) 결론이 바뀌지 않는다.

### 주 분석 — 통합 (40문항 × 3인 = 120판정)
- proposed 112/120 = **93.33%**, Wilson 95% CI [.874, .966], 이항검정 p < .001
- 만장일치 34/40 (85.0%), 다수결 우세 38/40 (p < .001)
- 평가자별 39/40(.975), 36/40(.900), 37/40(.925)
- 관측 일치도 P̄ = .900 / Pₑ = .876 / Fleiss κ = **.196** / Randolph κ = **.800** / Gwet AC₁ = **.886**

### 보조 — 차수별
- 1차(1–20): 57/60 = 95.0% / P̄ .933 / Pₑ .905 / Fleiss .298 / Randolph .867 / AC₁ .926
  — 만장일치 18/20, 다수결 우세 19/20
- 2차(21–40): 55/60 = 91.7% / P̄ .867 / Pₑ .847 / Fleiss .127 / Randolph .733 / AC₁ .843
  — 만장일치 16/20, 다수결 우세 19/20
- 문항 구성이 전혀 다름에도 선호율이 유사 → 특정 문항 집합에 의존하지 않음.

### 사용 금지 값
- **ICC 0.804** — 폐기 대상 `rating3`에서 나온 값. 실데이터 ICC는 0.2대이고,
  이분형 강제선택에 ICC 자체가 부적절. 논문에서 삭제.
- **`rating3` 시트 전체** — rating2와 일치 패턴은 같은데 marginal만 61:59로 맞춰
  Fleiss κ가 0.7999가 나오도록 구성됨. `ECRA 초안_국문_IRR 추가.docx` §4.2에
  "만장일치 34개 중 절반을 baseline으로 변경"이라는 조작 절차가 그대로 적혀 있다.
  **KCI 제출본에서 반드시 제거.**
- **양방향 매칭 44.1%** — 재현 데이터 없음. 해당 절 삭제함.

### 보고 방침
관측 일치도 + Fleiss(낮아도 생략 없이 병기하고 카파의 역설로 설명) + Randolph
free-marginal κ + Gwet AC₁ 삼각 검증. GRRAS(Kottner 외, 2011)에 따라 산출한 지표는 전부 보고.
39/80(48.8%)은 전체 정확도가 아니라 **baseline 실패 집합의 교정률**임을 일관되게 유지.

설문 40문항은 **challenge set 80건에서 뽑은 것이 아니다**(원자료 대조 결과 14건만 겹침).
두 시스템 출력이 뚜렷이 구별되는 사례를 저자가 고른 **목적표집**이므로, 원고에는
"80건 가운데 40건 선별"로 쓰지 말고 별도 표집임과 표집 편향 가능성을 밝힐 것.
따라서 48.75%와 93.33%는 표본이 달라 직접 비교되지 않는다.
